# 🚀 Análise de colisões com Ruby

Este projeto alimenta um vetor de tamanho N informado pelo usuário através de duas formas, buscando entender a diferença de tempo para completar cada versão. Uma versão(version1) possuí colisões presentes, ou seja, os numeros gerados através de sorteio sofrem com repetições, enquanto a outra versão(version2) não possuí essas colisões, a diferença principal é na maneira que o laço while é executado, mudando a maneira em que o método nativo da linguagem ruby rand é manipulado dentro dele.

---

## 🛠️ Tecnologias

* **Linguagem:** Ruby
* **Dependências:** Bundler e recursos nativos do ruby
